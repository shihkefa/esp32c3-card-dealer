V1.0.0 使用與首次測試

燒錄：
1. 解壓完整資料夾，保留CardDealer內的全部檔案，打開CardDealer.ino。
2. Arduino IDE安裝/選用「esp32 by Espressif Systems」3.x；本次測試為3.0.5。
3. Board選ESP32C3 Dev Module，USB CDC On Boot=Enabled，Flash Mode=DIO，Flash Size=4MB。
4. 依接線與供電.txt先切開JP-ESP5V，使用開發板USB資料線接電腦；不是TP4056充電口。
5. 選正確USB序列埠後上傳。第一次找不到埠，可按住板上BOOT、按一下RESET，再放BOOT進下載模式。
   板上BOOT是GPIO9按鍵，與上罩的RUN不同。
6. 上傳後按RESET或重新上電。序列監看115200，可輸入help或status。
   status中的wifi_off與ble_off應皆為true；這是查詢驅動/控制器狀態，不是固定寫死的文字。
7. 只用原始碼上傳即可。bin中的merged.bin為整合映像，從0x0寫；app .bin不是從0x0寫。
   這些二進位僅適用本套接線、原生USB、4MB Flash設定；修改BoardConfig後須重新編譯。

首次空機測試：
先清空牌倉，確認 OLED 顯示設定值。固定圈步版本上電後即有每圈 8191.5 半步的發牌設定。
用紙片分別擋光電，在USB status中確認exit_blocked/home_blocked：未擋false、擋住true。
確認PCF四鍵都有回應。scan只探測程式設定的PCF/OLED兩個地址，0代表ACK，不是全地址掃描。
用jog feed 200、jog eject 200分別點動，確認輪子推牌向出口；每次限制500ms。
方向反了先交換對應直流馬達兩線。點動會影響牌位置，不計入正式局數，測完重排牌。
如需量測機構，長按 SET 約 1 秒進入進階設定，切到「圈數校正」，短按 RUN 開始。日常發牌可直接跳過這項。
圈數校正只轉向，不開取牌/出牌馬達。需清空牌倉，約1至2分鐘，取得4個完整參考週期。校正固定以每秒 400 半步、加速度 200 半步/秒² 慢速量測，方便比對不同次結果。最近四次校正有獨立紀錄，一般發牌不會洗掉它們。輸入 cal status 或 cal export 可查閱，詳見「診斷與故障碼.txt」。
發牌方向以從機器正上方看出牌口為準。待機時長按 SET 約 1 秒，短按 SET 到「轉向方向」，按 − 選逆時針、＋ 選順時針，短按 RUN 儲存。重新對準首位後再按 RUN 發牌。此設定也決定手動圈數診斷的旋轉方向。
校正完成後儲存這次的量測紀錄。發牌一律以固定的每圈 8191.5 半步分配。對準第一位即可開始。
若選用校正診斷而量測失敗，先查 P25/P26 光電訊號、I2C 與齒輪。

日常操作：
短按SET：依次選每人張數、玩家人數、餘牌張數。
短按−/+：減/加；按住可連續調整。玩家人數為3或4。
總量不得超過108張，無效設定不套用。切到4人時若超量，先降低每人/餘牌數。
改這三欄後變成「自訂」，不會自動猜牌倉內總張數。請放入正確張數。

長按SET約1秒：進階設定。
進階內短按 SET 可選遊戲、校正、各檔 PWM、時間與轉向參數。「轉向速度」供兩種模式共用。之後依序為「轉向加速」、「轉向模式」、「落點微調」、「轉向方向」和「返回」。
−/+調值，短按RUN確認並返回；圈數校正項的RUN為啟動校正。
長按SET也可返回並保存。一般修改停止約2秒後會自動保存。
PWM是0至255的輸出比例，本版允許40至255；不是轉速回授。
「一檔時間」決定每張發牌時 RF300 以一檔 PWM（預設 255）起轉多久。範圍 0 至 500 ms，預設 100 ms。按 ＋／－ 選擇下一個或上一個 10 ms 刻度，短按 RUN 儲存。USB 可輸入整數毫秒，例如 set eject_start_ms 95。設為 0 時直接以二檔（預設 200）起轉。進入二檔後至少等 80 ms，N20 才開始取牌（預設 175），RF300 以二檔送完該張。
若想提早降速，可先維持兩檔 PWM，試將「一檔時間」從 100 ms 改成 90 ms，再以同種牌試發。若輪子偶爾無法起轉，回到前一個能穩定起轉的時間。若已穩定起轉但牌仍飛太遠，再將二檔 PWM 從 200 每次減 5，確認紙牌能完整離開出牌輪。兩檔 PWM 各可設 40 至 255。
出口有效遮光後，取牌輪一次性倒轉；預設反轉PWM175、反轉時間50ms（含換向停頓）。
反轉PWM可設0（停用）或40至255，反轉時間可設0（停用）或10至300ms。
兩者任一設0即停用。每次有效遮光只啟動一次倒轉，持續透光 12 ms 或反轉時間到即停止取牌輪。
出牌輪仍正轉拉出本張；反轉用於抑制下一張前進，不能保證完全消除雙張。
175僅是N20起轉參考，不是保證低轉速；由能穩定倒轉的值向下試，太低可能只抖不轉。
先單張，再少量牌測試反轉；較長的牌、不同紙面摩擦與電源瞬態需重測。
「轉向速度」可調 1% 至 100%，每按一次調 1%。1% 對應每秒 100 個指令半步，100% 對應每秒 10,000 個指令半步。新機預設 6%、加速 300 半步/秒²。舊機原有的 3600 會顯示 36%。加速度獨立可調 100 至 24000 半步/秒²。實機速度仍受行程、負載、加速和是否失步影響。
若速度已設 3600，加速超過 1000 就偏位或報 E07，並且聽見抖動或跳一下，先斷電檢查 P05B 軸夾是否在馬達軸上打滑、P05A 與大齒輪的咬合，以及 P26 能否順利穿過 P25 光槽。讓機器靜止，用紙片遮住、移開歸零光電，確認 USB status 的 home_blocked 隨之切換。
清空牌倉後，用 OLED「圈數校正」或 USB calibrate 慢速運轉。通過後，對準第一個位置，恢復最後能準確對位的速度／加速，再用少量牌測試。如需試值，先試速度 3600、加速 800。仍會抖動就將加速降至 600，若仍偏位則回到速度 600、加速 300，依「診斷與故障碼.txt」檢查 E07。
以 8192 半步/圈作軟體模擬，加速 800 或 1000 時，轉 90° 或 120° 都會在達到速度 3600 前開始減速。把速度上限從 3600 提到 7200，這兩種角度的轉向時間相同。
加速度（半步/秒²）   90°（四人）   120°（三人）
800                 3.075 秒      3.572 秒
1000                2.762 秒      3.203 秒
7200／24000 僅供手動試驗。上述時間含轉向加減速，實機負載、是否失步和每張送牌時間須另外觀察。
舊版 CDR1 至 CDR4 的牌數、取牌 PWM、轉向速度與加速度照原值載入，新增「一檔時間」預設 100 ms。原單檔出牌 PWM 沿用作二檔，一檔採 255。舊有兩檔設定與既有反轉值均可保留。

預設：
鬥地主：3人，每人17，餘3，放54張。
摜蛋：4人，每人27，餘0，放108張。
四人十三：4人，每人13，餘0，放52張。
三人十三：3人，每人13，餘13，放52張。

每局先把「整台」機器面向第一位玩家，不硬扭通電中的旋轉頭。
短按RUN開始。第一張直接朝目前方向發；3人每張轉120°，4人每張轉90°。
第二位在選定方向上的下一個座位。沿該方向從第一位量 60°（三人）或 45°（四人），即為餘牌集中發出的中間位置。
發完不自動轉回第一位，下局重新對準目前出牌方向即可。

連轉發牌
1. 待機長按 SET 約一秒，短按 SET 到「轉向模式」，按 ＋ 選「連轉發牌」，短按 RUN 儲存。原設定及新機均預選「停穩發牌」。長按 SET 重新進入「轉向速度」，建議首次連轉從 12%（1200 半步/秒）試起。「落點微調」先選 0 ms。
2. 試發可設四人、每人兩張、餘牌零，手動對準第一位再按 RUN。第一張停穩發，用 N20 開始取牌到 P24 確認牌尾離開的時間估計提前量。往後以連續走過各玩家方向的方式發牌，韌體會依加減速段及最近的送牌時間安排兩顆馬達啟動。連轉依「轉向加速」起停。你的機器過去加速超過 1000 容易跳齒，首次可採 800 或最後穩定值。
3. 有餘牌會停在第一和第二位正中間，把餘牌都發在同一處。餘牌為零時，最後一張在最後一位的方向停穩發。短按 RUN 暫停時，已啟動取牌就先完成該張，再減速。恢復後第一張停穩發，若煞停時已越過該玩家，會沿所選方向再轉一圈找回其方向。
4. 若移動中發出的牌一直越過玩家，將「落點微調」加 10 ms 提早取牌。反之減 10 ms，可設 −150 至 +150 ms。韌體持續記錄角度差，允許紙牌提早或延遲離開。若下一位玩家的方向已經越過，系統仍照原玩家順序安排下一張。光電只能確認牌通過出口。
5. 以每圈 8191.5 半步估算，1200 半步/秒穩速下每轉 90° 約 1.71 秒、120° 約 2.28 秒。確認落點和歸零正常後，可以每次增加 1% 再試。穩速 16%（1600 半步/秒）時這兩個間隔約 1.28 秒、1.71 秒。這些數字不包含首尾起停，實際落點與能否持續轉動以滿載測試為準。

讀取機內紀錄
完成一局、故障或人工中止後，等紀錄寫完再斷電。機器發牌中以 RAM 暫存，直接拔電會失去當局尚未寫入的資料。正常完成可見 LOG SAVED。USB 使用 SuperMini 的資料口，接線依「BIN燒錄說明.txt」所列的 JP-ESP5V 方式。待機時在 115200 序列埠輸入 log status，然後輸入 log export，即可讀出最近一局。較早的紀錄依序使用 log export 2、log export 3、log export 4。也能用 tools/read_deal_log.py 匯出 CSV，參閱「診斷與故障碼.txt」。

暫停與中止：
發牌中短按RUN：已進牌則等該張完整出完，才暫停；定位中等定位完成，尚未進牌則不啟動取牌。
暫停時保持步進位置，短按RUN繼續。暫停期間不要手動轉頭。
長按RUN約1.5秒：停止驅動輸出並取消本局；不是機械剎車，轉動件仍可能有慣性。
故障/中止畫面中，清牌後短按RUN只作重置，回待機；重新整理整副牌後，再按RUN開始新局。
故障局不恢復，重啟也不斷電續發，避免無法確認中途已飛出的牌。

實機調整：
先用1張/少量牌驗證出牌口計數，再逐步測10/54/108張。
正確的分牌閘、摩擦墊、O圈夾持和供電仍是必要條件，程式不能替代機械單張分離。
單個光電看到一個連續遮光脈衝時，無法知道是否有完全重疊的兩張牌。
若當前機構慢，只調PWM不會加快28BYJ-48逐張90/120°轉向，2至4張/秒仍不能保證。
