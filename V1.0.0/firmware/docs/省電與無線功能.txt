V1.0.0 無線關閉與省電

每次開機在setup呼叫RadioPower::disable()：
1. esp_wifi_stop()停止Wi-Fi，esp_wifi_deinit()卸載Wi-Fi驅動。
2. btStop()停止並卸載藍牙控制器；ESP32-C3的藍牙為BLE。
3. 驅動從未初始化是正常情況，不會為了關閉而先啟動無線。
4. 本套韌體沒有連網、掃描、熱點、BLE廣播、配對或重新啟用無線的程式。

待機、調整設定、發牌、暫停和故障時都維持關閉；重開機也維持相同設定。
操作使用上方四按鍵與OLED，診斷透過原生USB，不需要手機連線。
USB輸入status，可讀取wifi_off與ble_off。兩項都是依驅動/控制器當時狀態回報。
開機確認成功會輸出WIFI/BLE OFF；關閉回傳異常會輸出警告，不會假報成功。

本版不初始化Wi-Fi或BLE，並加入開機明確關閉與狀態確認。
因此不能將本次改動直接換算為節省多少mA或延長多少小時；尚未實機量測電流。
OLED、SuperMini板上LED、升壓板及光電感測器仍會耗電；關閉無線不代表整機進入睡眠。
本次不啟用Light-sleep/Deep-sleep，以保留按鍵輪詢、感測與步進計時器的原有時序。
發牌完成後會依原有流程釋放步進線圈；暫停保持位置時仍需通電，省電不可破壞定位。

接線依本套GPIO表及實物接線圖。
NVS設定格式保持相同；正常升級可沿用原圈數校正與參數。
