Overview

This is a PCF8574 IO expansion module suitable for MCU I/O expansion. It supports two types of access to the target board interface: pin or row of seats.

It can connect up to 8 PCF8574 IO expansion board to the I2C bus, providing up to 64 I/O ports. This is applicable in projects that needs control of LEDs.

Specifications

  • Voltage: 2.5 V to 6 V
  • Current consumption: 25 mA
  • Communication I2C at maximum frequency of 100 kHz
  • I2C 3 pins can be selected so that it can bind up to 8 modules on the same bus
  • Standby current: 10 mA (maximum)
