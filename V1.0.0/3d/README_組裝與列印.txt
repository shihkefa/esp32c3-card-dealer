【已確認需求】
牌倉內寬61，不設後擋板或定長槽；前緣仍需對齊分牌閘。參考57×87與60×96牌。
整組取牌、分牌與出牌路向出口傾6°，靠牌疊自重落牌，無上方壓簧或導桿。
少牌壓力不足才放P10滑板與P11配重；滑板可自由下降。配重實際填充率與重量待試。
108張容量以每張0.30厚規劃，實際厚度、翹曲、摩擦與單張分離需測試。
57mm牌裝兩片P12，左右件用同檔、第二件轉180°；內寬約58。
使用57mm牌時，P24連同出口光電元件向內移1.5，M3固定螺絲仍在P23原孔中。
使用者已有ESP32-C3、18650 2900mAh、5V2A充電器和A1 mini，均列入BOM但不算新增採購。

【建議組裝順序 — 依已檢查的子組裝路徑】
1. 先印P30、輪芯夾座與一顆P27，量測實購馬達、滑環、軸承、螢幕與板件後再打印大件。
   所有固定螺絲皆為M3×8或M3×25內六角沉頭；螺母均M3厚2.4、對邊5.5。勿混入舊清單。
2. P02B從原三個小開口放標準M3螺母，推至六角深槽止擋；可暫用M3×25拉入，再取下長螺絲。
   先放6005ZZ，再從P02A底面裝入P02B；三個定位凸臺與主板孔對齊，凸緣貼住主板底面。
   用新版P03由上方蓋住，削平側朝P05小齒輪；三顆M3×8穿P03、主板，鎖入P02B捕捉螺母。
   三顆先都咬合，再分次均勻鎖緊。不需在這三孔攻牙，不把M3×25留作正式固定。
   先以兩顆M3×8把步進馬達固定到P02A，讓輸出軸從現有孔露出。P05B預放橫向螺母及M3×8。
   從P02A上方把P05B套到D軸，用匹配的常見2mm L型工具從上方進入調緊；尺寸依新工具圖核對。
   再從左右側放兩顆齒輪連接螺母、套上P05A；兩顆M3×8從上方固定，交替輕鎖，使下裙封住側載出口。
   P04B四個螺母槽先放標準M3螺母；將P04A定位榫對準P04B凹槽，四顆M3×8由P04A上方鎖入。
   四顆輪流輕鎖，確認接面貼合。P03固定後，將P04A/P04B子組裝從上方穿入原高度軸承；不在軸承下加墊片。
   使用加高1.5mm的本包P04B，確認P04A底面與P02A頂圈名義間隙2.0mm。P04A原列印件不改。
   P06從底端套入前，先把M3螺母由上方插到側孔軸線；對齊P06通孔與P04B的Ø3.4徑向孔後再裝徑向螺絲。
   不帶螺絲硬套；P06圓環端面接觸軸承內圈，外凸部分低於端面。螺母插入路徑詳見P04分件說明。
3. 將滑環轉子從底部穿入空心軸；一顆M3×8穿過P06螺母及P04B孔，逐步輕調至接觸參考轉子夾持段。
   P06螺絲頭沉孔保留內移空間，不以頭部到底作鎖緊標準；過度旋入可能損傷滑環或阻礙轉動。
   本步在底盒尚未關閉時操作。核對實購滑環的轉子段，避開導線與固定外殼；實際保持力仍待試裝。
4. 確認P05A/P05B已在第2步完成鎖軸與連接，再檢查與P04B齒輪的嚙合及手動轉動。
   P02A的孔供P05B下端避讓；若需重調橫向夾緊螺絲，先拆回P04及P05A未裝狀態，再用匹配L型操作P05B。
   步進馬達固定最終用兩顆8mm；底座螺母先放入上移後的側槽，依本版側槽高度裝配。
5. 裝原高度P25參考感測器與本包P26遮光臂；各用8mm。P26薄片已向下延長1.5mm，仍穿過光電槽中央，螺絲頭保持齊平。
6. P31用四顆8mm固定到P04A。輪芯/軸承/上滑塊先作子組裝，左右軸承座沿鋼軸由外側套入。
   P13/P14四顆底腳8mm位於加高座，孔位已向外移；底腳與轉接框須配套使用。
   上、下輪芯各用一顆8mm和M3螺母夾軸，螺帽由底面的六角凹孔置入。尚不裝聯軸器/外罩。
7. N20底座用兩顆8mm，壓片也兩顆8mm；壓片耳已加厚避開牌倉中肋。
   取牌輪用一顆8mm＋M3螺母夾緊3mm D軸，不再用止付。
   P22兩端各裝M3螺母及8mm，分別夾2mm與3mm軸；保留軸向間隙並檢查兩軸同心。
8. RF300裝P20/P21，兩顆25mm同時穿過壓片、馬達座至P31螺母，沒有另外兩顆底座螺絲。
   先放好兩顆M3螺母，逐側均勻固定；拆馬達壓片時馬達座亦會鬆開。
9. P07/P08牌倉用四顆25mm；P09的兩顆8mm改從P08後方凹孔向前穿入，M3螺母放P09前側長槽。
   橡膠墊嵌入閘面凹袋。先調閘底0.45，再依牌厚找一張可過、兩張受阻的位置。
10. P23兩側各一顆8mm。P24用一顆8mm與M3螺母，頭面不進牌路。
    57mm牌裝兩P12；P24連同出口光電向內移1.5，螺栓/螺母仍在P23固定軸線上。
11. 先在機外預放P32A四顆連接螺母，讓P32B從負Y滑入A的屋頂及兩側包覆邊下、對準搭接，以原四顆8mm從內側向上連接；再裝P28/OLED兩顆8mm、P35按鍵板/PCF支架四顆8mm。接腳採低矮焊線。
    放四顆P27、檢查下壓/回彈，再讓預裝UI的上罩由上方罩入空牌倉。
    預放三顆上罩M3螺母，從P04A底面用三顆8mm固定P32A/P32B。裝P34兩顆8mm，P33四顆8mm。
12. P01內放電池盒/板件，用橋座束帶及P29固定。預放四顆底盒M3螺母，位於上移後的側槽。
    在滑環參考法蘭上預放三P36與捕捉螺母，小柱對準參考孔圓Ø38；必要時先暫時固定壓片。
    壓片定位柱不承擔最後鎖緊；不同法蘭可改柱位或去柱後暫定位，不擴鑽外購滑環。
13. 整個P02A/P02B/旋轉頭/滑環/三壓片垂直放到底盒。由底座三個凹孔向上裝三顆8mm，鎖入P36螺母。
    先使三壓片都咬合再均勻固定，法蘭貼住內側支承。這三顆螺絲從底部操作，勿從頂端硬找。
    復核步進馬達兩顆8mm，最後用四顆25mm關閉底盒。導線留拆裝餘量，避免壓住或捲入齒輪。
14. 斷電手動確認整機一圈及輪芯一圈，先低速測1/10/54/108張，再調速度與夾持量。
    P10/P11只在少牌打滑時使用；所有開縫夾座需實測握持力、鬆動與旋轉平順度。

【維修及工具】
P05B的橫向螺絲以常見2mm L型操作，短臂尺寸依新工具圖核對；P02A與馬達先就位，P05A/P04及上罩尚未裝。
已核對短臂端點至長臂中心距14mm、16mm參考工具；20mm參考會受P02A外圈限制，不能按商品外側總長直接判定。
P02A高邊會阻擋水平直柄工具；P05B法蘭也過不了P02A的Ø24mm孔，請依先底板/馬達、再B、再A的順序。
齒輪連接用兩顆M3×8從P05A上方操作；維修順序與工具檢查詳見P05分件說明及專用驗證報告。
P33可拆以清牌與接近近側機構；遠側滾輪調整需短臂約12mm的L型工具，預留直徑3mm。
一般較長短臂起子可能碰頂部支架，不能聲稱所有工具均能伸入；也可在上罩未裝前調好。
USB插頭以10×6膠殼參考，較粗包膠接頭需試插。Type-C是充電口，非外露的ESP燒錄孔。

P04A/P04B/P09/P12/P13/P14/P23/P32A/P32B仍需檢查局部橋接或支撐；P32A以Z128.7、P32B以降低後Z127.2的屋頂大平面向下，P36依STL方向打印。
2.7mm試配孔不是已生成的螺紋；孔徑、公差及收縮未實測。0.02mm³只是數值交集門檻。
軸承座47.3/10.3、空心軸24.8、鋼軸孔3.15等需實物試配；O圈真實變形與夾持量也需調整。
牌路、支撐殘留與接縫磨平。新夾緊結構沒有實測夾持力、鬆動壽命或高速動平衡結果。

【12路滑環與供電架構】
上罩I2C介面與旋轉頭採12路滑環，使用10路：
5V、GND、3.3V、SDA、SCL、N20 IN1、N20 IN2、RF300 PWM、出口計數、旋轉參考，餘2路備用。
OLED/PCF用3.3V；SDA為GPIO21、SCL為GPIO20。逐腳接線依同專案wiring/內的實物接線圖。
指定PCF長條板與X113647驅動板固定座仍需依實物試配或調整，既有模型檢查只涵蓋參考包絡。
18650→1S保護板B端；TP4056電池端和負載都接保護板P端，不旁路保護。
P+→總開關→5V升壓→ESP開發板5V輸入及馬達/驅動。3.3V邏輯全部共地。
USB Type-C→TP4056；此版關機充電，TP4056未提供邊充邊用電源路徑管理。
只確認2900mAh，需核對電池為單節充滿4.2V的鋰離子及允許充放電電流。
先以0.5A充電選料，PROG典型約2.4kΩ，仍依板件資料設定；Type-C選支援C-to-C板款。
升壓板先量得5.0V，再核對低電量及馬達啟動時供電，不將芯片開關電流當成模組輸出電流。
DRV8833及兩顆馬達電流/散熱尚未量測；本檔不是完整電路原理圖或韌體。

【發牌模式與速度】
每次開始將整機面向第一位，記為0°；四人逐張90°，三人逐張120°。
餘牌集中發在第一/第二位中間：四人45°、三人60°。
鬥地主3×17+3=54；摜蛋4×27=108；四人13張=52；三人13張若放52則餘13。
韌體把開始時朝向作第一位；旋轉參考用於校正與檢查，不會先歸零改變第一張的方向。
保留28BYJ-48及60:30的2:1外部減速，逐張90/120°轉向較慢，不能達成每秒2至4張的保證。
若用名義4096半步/馬達輸出圈、600半步/秒作計算示例，90°約3.41秒、120°約4.55秒。
這不是實測或允許步頻；實際齒比、負載、加速度需校準。原速度目標需另升級轉向傳動。
