發牌機 V1.0.0　組裝與列印

STL 資料夾有 41 種正式零件。每份 STL 採毫米單位，已擺在建議姿態。基本機構印 45 件；若選配 P10、窄牌用 P12 並列印 P30 試片，共 53 件。各零件名稱、尺寸、數量與材料列於 parts_manifest.json。完整裝配順序請開專案內 manual 資料夾的 3D 說明書。

拓竹 A1 mini

P04A、P09、P10A、P10B、P10C、P10D、P24、P28 和 P32A 提供 3MF。P04A 的六個支撐阻擋體可避免螺母井塞滿支撐；切片後查看層預覽，確認主底面貼床和螺母通道可用。其餘零件可將對應 STL 載入切片器。依實際耗材選材料設定。

選配 P10 壓牌擺輪共四種、五件。P10A 擺架、P10B 自由輪、P10C 隔套各印一件；P10D 側夾同一檔案印兩件。四份 3MF 各含一件，材料用 PETG。M3×25 輪軸和螺母壓住隔套後，輪仍應自由轉動。左右側夾一起調整，確認輪緣能貼牌倉底板，並與 P17 取牌輪保有間隙。

裝配與試轉

• P01 滑環固定柱高 23 mm。P02 底面貼合四根底盒螺絲柱。固定的 28BYJ-48 馬達和轉動的小齒輪軸採 55.0 mm 設計中心距，配 P05A 30 齒和 P04B 60 齒。P05B 的 D 形夾孔為 5.1 × 3.1 mm。
• P04A 四個牌倉螺母和兩個馬達座螺母需先從底面裝入。P06 在 6005 軸承下方，先裝其螺母，再從上方插入 P04B 空心軸並對孔鎖付。
• 牌道寬 61 mm，參考用牌為 57 × 87 或 60 × 96 mm。P09 下段 30° 貼面跨整個牌道，55 × 4 × 1 mm 橡膠置中。喉口可從 0.45 mm 起依實際牌厚微調。
• P13/P14 外側大平面貼床。上方 82 mm 鋼軸置中，P31 距兩軸端各有 0.5 mm 名義間隙。鎖好調整螺絲後確認上滾輪仍可自由轉動。
• P28 以兩支 M3×8 固定 OLED。壓舌應接觸 PCB 邊緣，玻璃面須留出空間。
• 標準空機五金為 DIN 7991 M3×8 56 支、M3×25 10 支、M3 螺母 47 顆及 M3 墊片 3 片。加裝 P10 時另加 M3×25 一支與 M3 螺母一顆。
• 裝妥後斷電手轉一整圈，核對 P05 與 P02、P26 遮光片與原點光電之間的實際間隙。P26 薄片內緣半徑 77 mm，相對 P05A 齒頂回轉包絡的名義間隙為 2 mm。實際馬達支架、開關、USB 小板、光電槽深、承重變形和列印公差都會影響配合。

可編輯模型與組裝預覽

在 OpenSCAD 直接開啟 OpenSCAD 資料夾的單件，可檢視和修改 CSG 幾何；card_dealer.scad 提供組裝及具名零件。列印時選單件 STL。整機及選配 P10 的兩份組裝 STL 內含各零件的獨立殼體，可用於查看裝配位置。

Python 參數與形狀定義位於 source。使用 Python 3.12，在此 3d 目錄執行：

  python -m pip install -r source/requirements.txt
  python source/build_cad.py export
  python source/export_assembly.py

模型匯出至 generated。export 會產生單件 STL、OpenSCAD、尺寸與五金清單。若 CSG 文字與正式單件相符，沿用正式 STL 的精確位元；加工後的幾何會重新網格化。export_assembly.py 匯出標準及含 P10 的整機預覽。修改形狀後應重新檢查裝配與切片設定。
