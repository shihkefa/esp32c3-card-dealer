充電式撲克牌發牌機 V1.0.0

本資料夾統一使用V1.0.0，P04A與P02A頂圈2mm間隙修訂日期2026-11-11，包含目前的機構、BOM、實物接線圖、韌體及直接燒錄檔。
Wi-Fi與藍牙BLE保持關閉，使用上方四按鍵及OLED操作。

直接燒錄：
晶片ESP32-C3；Flash 4MB；DIO；完整整合BIN從0x0000寫入。
使用SuperMini自己的原生USB資料口。連接電腦前先拔除JP-ESP5V，GND維持共地。
找不到下載埠時，按住BOOT，按一下RESET，再放開BOOT。
完整整合映像會覆寫NVS設定及圈數校正，燒錄後要重新設定與校正。
燒錄完先空機測感測器及馬達方向，再按firmware/docs/使用與首次測試.txt校正。
USB輸入status可確認wifi_off及ble_off均為true。
只更新主程式與完整整合映像不同；其他BIN的用途見firmware/docs/BIN燒錄說明.txt。

操作與機構：
每局將整機出牌方向對準第一位玩家。3人逐張120度，4人逐張90度。
餘牌發到第一與第二位的中間。牌倉內寬61mm、前後不限長、向出口下傾6度。
使用重力落牌，P10/P11為選配上方配重。每個列印件保留隱藏式凹刻編號。
螺絲只有DIN7991 M3×8及M3×25；模型用量61支及10支，M3螺母52顆。

P02分件：原P02改為P02A平底主板及P02B軸承座，必須搭配新版P03。
三處小孔改六角防轉螺母槽，須將螺母推至深槽止擋；詳見3d/P02_分件與螺母裝配.txt。

P04分件：P04A為上承載盤，P04B為60齒輪與空心軸；四顆M3×8及M3螺母連接，矩形榫防轉定位。
P04A上方大平面朝床，P04B齒輪平面朝床、空心軸朝上；小槽局部橋接仍需切片確認。
P06新增上方插入的M3捕捉螺母；徑向螺絲不再靠塑膠咬牙，須輕調接觸滑環，勿強鎖到底。
P04B齒輪頂與接合面Z43.5mm、齒底Z36mm；P04A原件及P06沿用，軸承不墊高。P26薄片向下延長1.5mm，配合原高度光電；詳見3d/P04_分件與螺母裝配.txt。

P05分件：P05A為完整30齒輪，P05B為獨立閉合D軸夾座，兩件須配套使用。
P02A與馬達先就位，P05A暫不裝；P05B套D軸後以匹配的常見2mm L型工具調緊，再裝P05A及兩顆M3×8。
P05A下裙封住側載入口，P05B保留完整沉頭錐座及閉孔，限制五金歪斜與退出；夾持力仍須實測。
P05B以新增負Y削平面貼床，兩端45°削角逐層銜接法蘭；建議3–5mm brim，孔槽小橋接仍需切片確認。
P05A內腔平口Y−10.7對應P05B平口Y−10.5，名義側隙0.2mm；只調整齒輪內部避空，完整30齒、螺絲孔與防脫裙邊保留。
平口P05A與平面P05B在本次2mm間隙調整中均可沿用；試配時勿用螺絲強拉未就位的接合面。
平口配合位置見3d/P05A_P05B_平口配合.png。
平面與列印方向見3d/P05B_平面貼床與削角.png；每個STL已匯出為對應列印姿態。
原P05.stl及舊P05工具圖停止使用。詳見3d/P05_分件與閉合夾座裝配.txt。

P32上殼台階包覆：先讓P32B由負Y滑入P32A屋頂及兩側包覆邊下，再用原四組M3×8與標準M3螺母從內側連接；完成後裝原UI，最後整組罩入。
含原P33的前視左右外緣為±98.2mm，總寬196.4mm；上下中心對齊，並非上下外緣同寬。P33/P34及原孔位沿用。
