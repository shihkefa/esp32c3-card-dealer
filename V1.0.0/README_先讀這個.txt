ESP32-C3 旋轉撲克牌發牌機　V1.0.0

1. 開啟「發牌機_BOM_V1.0.0.xlsx」查看電子零件、五金及列印數量。
2. 開啟 manual/發牌機_組裝說明書_V1.0.0.html。可離線旋轉或縮放模型，依步驟組裝。
3. 單件 STL 位於 3d/STL，3MF 及列印注意事項在 3d/README_組裝與列印.txt。根目錄的整機 STL 供查看裝配位置。
4. 開啟 wiring/開啟我_互動實物接線圖.html，或查看同資料夾的逐腳接線圖 PDF。
5. 依 firmware/docs/BIN燒錄說明.txt 選擇整合或單獨主程式映像。
6. 待機時長按 SET，短按 SET 切到「轉向方向」，按 ＋ 選順時針或按 － 選逆時針，短按 RUN 儲存。方向以從上方看機頭為準。
7. 對準第一位玩家，確認玩家數、每人張數及餘牌數後按 RUN。操作及所有錯誤代碼在 firmware/docs。

各檔案的 SHA-256 校驗值列於同目錄 SHA256SUMS.txt。
